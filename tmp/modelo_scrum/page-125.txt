1.4. Product Backlog Priorizado 
El Product Backlog Priorizado define el alcance del proyecto y establece el orden de 
importancia de cada funcionalidad. La priorización permite enfocar el desarrollo en los 
elementos que aportan mayor valor al sistema Intersegur SCM, asegurando una 
entrega eficiente y alineada con los objetivos estratégicos. 
Prioridad 
Para estructurar la prioridad de los requerimientos, se emplea la técnica MoSCoW, 
que clasifica las funcionalidades en cuatro niveles: 
Tabla 4. Prioridad según técnica MoSCoW 
Abrev. Prioridad Definición 
M Must 
Have 
Funcionalidades esenciales que el sistema debe incluir para 
ser operativo. Sin ellas, el proyecto no cumple su propósito. 
S Should 
Have 
Funcionalidades importantes que deberían estar presentes, 
pero cuya ausencia no impide el funcionamiento básico del 
sistema.
