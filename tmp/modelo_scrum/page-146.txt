 
Tabla 35. Requerimientos del Sprint 1 
Requerimientos 
El sistema debe tener una ventana de inicio de sesión permitiendo el ingreso por 
medio de un usuario y contraseña. 
El sistema debe tener un módulo de usuarios en donde se podrá gestionar la vista, 
creación, modificación y desactivación/activación de un usuario. 
El sistema debe ejecutar un proceso de ETL que extraiga datos históricos de fechas 
y los cargue en la tabla DIM_TIEMPO del Data Warehouse para alimentar la 
inteligencia de negocio.
