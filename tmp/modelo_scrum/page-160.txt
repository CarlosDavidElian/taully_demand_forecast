 
• Prueba de caja negra del RF03 
En la Tabla 37 se muestra la prueba de caja negra 2 aplicada al módulo de gestión 
de usuarios. Esta prueba tiene como objetivo verificar que el sistema permita registrar, 
listar y editar usuarios correctamente, de acuerdo con los criterios definidos en la 
estructura de la tabla usuarios. 
Tabla 37. Prueba de caja negra 2 
PRUEBA DE CAJA NEGRA 2 
Código PCN-02 Fecha 04/04/2025 
Tarea Administrar usuario Módulo Gestión de usuarios 
Descripción 
Se ejecutarán pruebas para verificar si el sistema realiza 
correctamente las validaciones al registrar un nuevo usuario, 
controla duplicidades y permite modificar registros existentes en el 
módulo de gestión de usuarios. 
Precondiciones 
• El usuario administrador ha iniciado sesión exitosamente 
• El módulo de gestión de usuarios está disponible en el menú principal 
Pasos de la prueba 
• Validar los campos obligatorios del formulario de registro 
• Validar que el sistema no permita registrar usuarios con campos duplicados (dni, 
email) 
• Validar que el sistema permita guardar el usuario con datos válidos 
• Validar que el sistema muestre el usuario en el listado después del registro 
• Validar que el sistema permita editar un usuario y reflejar los cambios  
correctamente
