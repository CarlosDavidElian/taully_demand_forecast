• Funcionalidades del Sprint 3 
En la Tabla 53 se describen las funcionalidades que tendrá el sistema, mostrando la 
interacción entre el usuario y la arquitectura de software para cada uno de los 
requerimientos listados en el Sprint 3. 
Tabla 53. Funcionalidades del Sprint 3 
Código RF Funcionalidad 
RF09 
Se desarrolla el proceso de ETL que extrae información detallada de 
pedidos desde el archivo fuente, normaliza las relaciones con 
dimensiones y carga los registros en FACT_PEDIDOS. 
RF10 
Se implementa el proceso de ETL que procesa datos de inventario 
consolidando cantidades, fechas y ubicaciones, y los almacena en la 
tabla FACT_INVENTARIO. 
RF11 
Se diseña e implementa un modelo de predicción de demanda que 
utiliza datos históricos de pedidos e inventario para generar 
estimaciones por producto en función del comportamiento pasado. 
Fuente: Elaboración propia
