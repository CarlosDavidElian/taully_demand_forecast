 
Tabla 57. Requerimientos del Sprint 3 
Requerimientos 
El sistema debe ejecutar un proceso de ETL que extraiga y cargue los registros 
históricos de pedidos en la tabla FACT_PEDIDOS, integrando claves 
dimensionales. 
El sistema debe ejecutar un proceso de ETL que transforme y cargue las cantidades 
consolidadas de inventario en la tabla FACT_INVENTARIO. 
El sistema debe desarrollar un modelo de predicción de demanda que utilice 
información histórica para estimar el comportamiento futuro de cada producto.
