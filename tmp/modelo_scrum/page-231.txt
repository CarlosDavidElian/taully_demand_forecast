Tarea Verificar visualización del

Descripción 
Se ejecutarán pruebas para validar que el sistema presente 
correctamente los elementos del dashboard  correspondiente al 
requerimiento RF12. Esta interfaz debe mostrar métricas generales 
como el total de pedidos completados, tasa de cumplimiento (TCP), 
precisión de inventario (PI), y comparaciones por tipo de cliente, 
producto y fecha. La validación se enfocará en los datos agregados 
históricos obtenidos desde las tablas FACT_PEDIDOS y 
FACT_INVENTARIO. 
Precondiciones 
• Datos históricos disponibles en la base de datos dimensional 
• Cálculos agregados ejecutados previamente (PI, TCP, totales) 
• Elementos visuales disponibles (gráficos, tablas, métricas)
