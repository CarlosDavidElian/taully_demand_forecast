 
• ETL (Extracción, Transformación y Carga): Realizado con scripts en Python, 
donde se automatiza la lectura, validación y carga de los datos hacia la base 
de datos dimensional en MySQL. 
• Almacén de datos (Data Warehouse):  Implementado en MySQL, con un 
modelo dimensional en estrella que facilita el análisis multidimensional. 
• Motor analítico y Machine Learning:  Scripts Python con librerías como 
Pandas y Scikit-learn para modelado predictivo (predicción de demanda). 
• Visualización de datos:  Desarrollo de un dashboard interactivo mediante 
Flask como framework backend y Chart.js para la visualización web de los 
datos.
