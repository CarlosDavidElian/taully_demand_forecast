4.3. Implementación de cada componente 
a) ETL 
• Implementado con Python, utilizando las librerías: 
1. pandas: para limpieza y transformación. 
2. openpyxl: para lectura de archivos Excel. 
3. SQLAlchemy, mysqlclient: para cargar los datos en MySQL. 
• El proceso ETL se automatiza con scripts que pueden ejecutarse diariamente. 
b) Modelo dimensional en MySQL 
• Diseño en estrella con tablas de hechos (pedidos e inventario) y dimensiones 
(tiempo, producto, empleado, cliente, ubicación). 
• Uso de claves foráneas para garantizar la integridad referencial.
